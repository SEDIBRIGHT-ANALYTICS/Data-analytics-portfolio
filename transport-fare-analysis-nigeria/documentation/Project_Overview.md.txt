# TRANSPORT FARE ANALYSIS IN NIGERIA

## 1. Project Overview

This project examines transport fare patterns across different states, routes, and transport types in Nigeria using Microsoft Power BI and Microsoft Excel. It explores variations in transportation costs across geographical locations and transport categories, providing insights into how fares differ across the Nigerian transportation system.

The project involves dataset inspection, preparation, analysis, and interactive visualisation to transform raw transportation records into meaningful and accessible information.

## 2. Project Objectives

The objectives of this project are to:

- Examine variations in average transport fares across Nigerian states.
- Compare average fares across different transport types.
- Analyse the distribution of recorded routes across transport types.
- Identify routes with relatively high average transport fares.
- Explore differences in transportation costs across recorded routes.
- Present the findings through interactive Power BI visualisations.

## 3. Dataset Description

The dataset contains **52,500 records and 8 columns**, covering transportation information across Nigerian states, routes, and transport categories.

The dataset contains the following fields:

- State
- Transport Type
- Route
- Distance (KM)
- Fare (NGN)
- Notes
- Entered By
- Random Text

Following the standardisation of text entries, the dataset covers:

- **36 Nigerian states**
- **11 transport types**
- **226 distinct routes**

The dataset also contains fare information recorded in Nigerian Naira (NGN).

## 4. Tools and Technologies Used

- **Microsoft Excel:** Used for dataset inspection and preparation.
- **Microsoft Power BI:** Used for data modelling, analysis, and interactive visualisation.

## 5. Project Components

The Power BI report consists of two main pages:

1. **Chart:** Presents the individual analytical visualisations.
2. **Dashboard and Wireframe:** Provides the dashboard presentation of the analysis.

The analytical visuals include:

- Average Fare by Route
- Average Fare by Transport Type
- Count of Routes by Transport Type
- Average Fare by State

## 6. Data Preparation

Data preparation involved inspecting the dataset for missing values, inconsistent text entries, duplicate records, and issues affecting numerical analysis.

The preparation process also involved standardising state names, transport-type entries, and route descriptions, as well as reviewing fare values to support accurate numerical analysis.

## 7. Project Purpose and Significance

The purpose of this project is to demonstrate the application of data analytics and business intelligence techniques to transportation data in Nigeria.

By using Microsoft Excel and Power BI, the project illustrates how raw transportation records can be organised, analysed, and presented through visualisations that make transport fare patterns easier to explore and understand.
